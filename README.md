# Dayesh Late Portfolio

Personal developer portfolio built with React, TypeScript, and Vite.

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

## Getting Started

1. Install dependencies:

```sh
npm install
```

2. Start development server:

```sh
npm run dev
```

3. Build for production:

```sh
npm run build
```

4. Preview production build:

```sh
npm run preview
```

## Testing

Run tests with:

```sh
npm test
```
